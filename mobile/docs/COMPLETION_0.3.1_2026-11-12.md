# HisabNikash 0.3.1 — remaining-work completion

Review date: 12 November 2026, Asia/Dhaka. Source version **0.3.1+4**;
the iOS CI build is **0.3.1 (5)** because its build number uses the workflow run counter.

## Completed locally

- Inventoried application strings using the Dart AST. Bengali catalogs now cover
  the inventory’s user-facing messages, validation failures, recovery/sync states,
  navigation, selectors and report headings. Brand names, protocol identifiers,
  timezones and the existing CSV schema are intentional exclusions.
- Connected translations to form labels, validation, hints, tooltips, dialogs,
  summaries and dynamic messages. User-entered names/notes remain data, not
  translated storage values. Added catalog-coverage and language-switch tests.
- Corrected the About version and two masked-balance strings that showed `????`.
- Monthly and invoice PDFs use the selected app language. Bengali text is shaped
  by Flutter/Skia with the bundled fonts before embedding, so conjuncts and vowel
  marks render correctly. Latin text/numbers remain native PDF text. Bengali runs
  are embedded as high-resolution images and are not selectable as PDF text.
- Verified Bengali report creation and multi-page tables. Cached image providers
  are shared; mutable PDF layout widgets are not reused across cells.
- Fixed iPhone permission inspection to use the iOS permission API. Registered
  English and Bengali action categories; snooze follows the selected language.
- Added an explicit on-device notification check: permission, pending/delivered
  counts, immediate test and a scheduled test after one minute. It uses generic
  private content. No financial transaction is created by the test.
- Added native English/Bengali Face ID explanation resources to the iOS project.
- Added five platform-channel contract tests for iOS permission reads, native
  actions, reminder deduplication, daily/bill isolation and delivery-test behavior.
